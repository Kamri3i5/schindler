## 🐛 БАГИ — Исправить в первую очередь

### Баг 1: Секция Schindler 9300AE — эскалатор показывает лифт
**Проблема:** В секции продукта "Schindler 9300AE" (третий продукт, `/03`) написано "Эскалаторы", но в правой части (`.product-visual`) отображается анимация **лифтовой шахты с кабиной и тросами** вместо эскалатора. CSS-анимация эскалатора (`.escalator` с `transform: rotate(-30deg)` и `.escalator-step`) — ступеньки анимируются `translateY(-240px)` и уезжают за пределы контейнера, визуально пропадая. Сам контейнер `.escalator` повёрнут на -30° и его элементы вылезают за `overflow: hidden` родителя `.product-visual`.

**Как исправить:**
1. Убедиться что в HTML для третьего продукта (`data-product="9300"`) используется div `.escalator`, а НЕ `.product-shaft` / `.product-cab`
2. Исправить CSS-анимацию `.escalator-step` — ступеньки не должны уезжать за пределы видимости. Заменить `translateY(-240px)` на цикличное движение в пределах контейнера
3. Добавить `overflow: hidden` на `.escalator` чтобы ступеньки не вылезали
4. Уменьшить `transform: rotate(-30deg)` до `-25deg` и скорректировать размеры чтобы эскалатор вписывался в `.product-visual` (высота 480px)
5. Добавить перила (handrail) по бокам эскалатора — сейчас только одна линия `.escalator-rail`
6. Или лучше: заменить CSS-анимацию на **реальное фото/рендер** эскалатора Schindler 9300AE

### Баг 2: Неправильный путь к фото Hilton
**Проблема:** В `styles.css` строка ~701: `.project-pattern { background-image: url("Hilton.jpg") }` — файл лежит в `images/Hilton.jpg`
**Исправление:** Заменить на `url("images/Hilton.jpg")`

### Баг 3: Бургер-меню не работает
**Проблема:** Кнопка `.nav-burger` отображается на экранах ≤1100px, но в `script.js` нет обработчика клика. Меню невозможно открыть на мобильных.
**Исправление:** Добавить JS-логику:
- Клик по бургеру → показать fullscreen overlay-меню с навигационными ссылками
- Анимация открытия (slide-down или fade)
- Клик по ссылке внутри меню → закрыть меню + smooth scroll
- Клик по overlay / кнопке закрытия → закрыть меню

### Баг 4: Форма — заглушка
**Проблема:** `onsubmit="event.preventDefault(); alert('Форма-демо...')"` — нет реальной отправки.
**Исправление:** Подключить EmailJS или Formspree, или отправку через Telegram Bot API.
